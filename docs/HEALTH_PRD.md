# Airplane 财务与健康

财务和健康共用导航、快捷录入和离线更新。用户可以记录一笔采购、一餐饭或一次称重，随后核对余额、营养和库存。基于财务 0.7.23、健康 PR #1 和草稿 PR #2 迭代。

## P0 本地账本

- 今日、记录、库存、趋势、AI 助手、设置。核心记录和历史更正可离线完成。
- 食品保存营养基准、单位、来源及质量。未知值保留空值。计划、实际、取消是状态，补报和估算是记录属性。实际摄入与库存流水一起提交，编辑时刷新相同事件的流水。
- 按批次记采购、消耗、丢弃、盘点与分装。支持生熟重量比例和称重差计算。采购价格用于饮食成本分析，价格缺失时显示未知。
- 晨重用最近七次有效记录。消耗使用基础 TDEE 加未包含的活动，或使用设备全天消耗。次日结算，有补报时按日期重算。周期长度、锚点、目标缺口、日摄入参考从导入或本机设置取得。
- 财务和健康分别导出。统一备份可选包含的账本，恢复前预览并保存本机副本。旧财务格式和健康主账可导入。

## P1 采购和 AI

- 财务交易与采购用稳定 ID 关联。一笔采购可有多种食品。金额按分核对，未知价格无需虚填。重试只更新同一关联。吃饭只记录摄入和消耗。
- AI 从文字或图片生成候选，包括饮食、运动、采购和营养标签。规划读取选定的近期摄入、库存、周期和规则。每次发送前可查看数据。最终由用户确认提交。
- OpenAI Key 由服务器持有。浏览器使用单用户访问码。服务器核对来源，执行调用频率、每用户额度和总预算，保存用量元数据。模型与参数由服务端配置。

## P2

云同步、多人共享、健康平台自动导入和复杂报表。

## 验收

旧财务升级、健康主账重复导入、批次分装、包装扣重、跨日补报、计划转实际、采购重试、未授权拒绝、完整备份恢复、离线更新。开发测试全部使用虚构记录。iPhone 主屏幕更新需要实机验收。
