# Airplane 助手工作台

从财务或健康进入同一个全页助手。原有饮食、收支、采购和照片候选继续使用。工作台分为对话、待确认操作、Skill 与本轮上下文。

## 账本工具

- 查询库存：按名称取最多四项，返回名称、数量和单位。晚餐规划另外可取今天的热量、蛋白质和对应目标。
- 查询财务：只返回当天收入、支出合计和笔数。交易明细、备注和历史备份不进入模型请求。
- 写入：收支、饮食计划、摄入、运动、采购、库存盘点和补货生成可编辑操作卡。盘点用现有批次分配和库存流水。确认时检查最新版本，再由应用提交。
- 后续：采购一次确认同时入库并关联支出。设计沿用稳定订单 ID、恢复日志和余额校验。再增加按范围查询历史、指定记录更正和操作反馈。

## 后续日常流程

| 用户说法 | 工作台处理 | 账本展示 |
| --- | --- | --- |
| “昨天喝的是 300 g，改一下” | 查询指定日和食品，列出匹配记录，确认改动后重算库存与营养 | 健康历史、趋势和库存流水 |
| “今天早上 74.5 kg” | 识别称重时间和晨重，确认后保存 | 最新晨重和滚动均值 |
| “这袋鸡胸买了 28 元” | 同一张卡核对实付、分类和入库批次，两个账本统一提交 | 采购记录和财务支出显示关联 |
| “按我常吃的搭一份晚餐” | 读取经选择的库存和今日营养，返回结构化计划。执行后可转为实际摄入 | 计划餐和已确认饮食分别展示 |

只有完成这些常用闭环后，再统一验收真实模型、移动端和完整回归。

## Skill 与上下文

- 内置提示词随代码维护。个人 Skill 是最多 320 字的行为偏好。用户可编辑，也可请助手给出新版，核对并确认后保存。
- 每轮保留最近四条短消息，总共最多 900 字。旧照片不重发。每轮最多一次账本查询和一次结果提交。用户核对摘要后才发送查询结果。模型只可请求应用定义的工具。
- 允许用户新开对话、停止发送摘要、放弃候选或手动填写。对话文本、操作结果、个人 Skill 和 API Key 各自保存在设备。照片与工具原始摘要随本轮结束释放。

## Demo

从 `/assistant/?demo=1` 打开。独立的示例账本用于演示库存盘点、补货、晚餐、收支和 Skill。所有卡片走与正式版相同的预览和确认入口。在同一个标签页切换财务或健康可查看样例账本的变化，不需要 Key 或模型请求。
