# Airplane PWA 0.7.6

稳定版更新：

- 默认分类与自定义分类统一管理：均可编辑、隐藏、删除和拖动排序。
- 删除分类不会影响历史账单，历史记录继续使用保存时的分类名称、图标与颜色快照。
- 为避免记账页无分类可选，每种收支类型至少保留一个分类，且至少保留一个可见分类。
- 扩充日常图标：水费、电费、燃气、洗衣、房屋/物业、网络、订阅、快递、维修、停车、宠物、公交、地铁/火车、衣物等。
- 启动改为本地缓存优先，不再为了检查程序版本等待服务器。
- 后台更新检查最多每 12 小时一次，并延迟到启动后约 6 秒；发现新版只提示，由用户点击“更新”后切换。
- 设置中可随时手动“程序更新 → 检查”。
- 数据键仍为 `airplane-pwa-v1`，已有账单、预算、余额和分类无感继承。
- Service Worker cache: `airplane-shell-v13`.
- 0.7.6 的 Service Worker 保留一次 `skipWaiting` 作为从旧更新器迁移到新更新机制的桥接；从本版之后，新版本应保持 waiting，由用户确认更新。
