# Airplane PWA 0.7.10

- 预算、初始余额、余额调整与记账金额统一支持 + − × ÷ 表达式和快捷运算按钮。
- 记账页移除右上角保存，把主“完成/保存修改”按钮前移到分类与日期之后；时间和备注放到按钮下方作为可选信息。
- iPhone 底部 Sheet 支持从卡片任意位置向下拖动关闭；只有内容滚动到顶部且手势明确向下时才接管，正常滚动和点击不受影响。
- 修复“点击更新后提示新版尚未准备完成”的竞态：直接跟踪已安装的新 Service Worker，旧桥接版本已自动生效时也不会误报失败。
- 0.7.8 起 Service Worker 不再 install 时自动 skipWaiting；发现新版后等待用户点击更新，设置里也可手动检查。
- 启动仍然本地缓存优先，后台检查不会阻塞首页打开。
- 数据键保持 `airplane-pwa-v1`，已有数据无感继承。
- Service Worker cache: `airplane-shell-v16`.

- 0.7.10：修复分类编辑器保存后退出“整理分类”的问题；新增/编辑分类后继续停留在整理页，并自动把刚保存的分类滚动到可见区域。
- 同时移除旧更新流程遗留的无效弹窗关闭回调，避免保存分类等操作被 JavaScript 异常中断。

## 0.7.10 更新可靠性修复
- 修复“点击更新、Service Worker 已切换，但页面仍运行旧版”的问题。
- 新 Service Worker 安装时不再直接 `cache.addAll()`；所有程序文件都使用版本戳 + `no-store` 强制从服务器获取，再写入新缓存，避免 iOS HTTP 缓存或 CDN 旧副本被装进新缓存。
- 用户点击“更新”后，`controllerchange` 正常触发时立即重新载入；若 iOS 延迟/漏发该事件，4.5 秒后还有一次有界刷新兜底。
- 启动仍然是本地缓存优先，不把联网更新检查放回启动关键路径。
