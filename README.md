# Airplane PWA 0.9.0

Airplane 在设备上保存财务和健康账本。顶部「财务 / 健康」切换模块。健康页提供饮食、体重、运动、库存和可配置的周期汇总，记录页可以手动填写，也可以从智能助手的候选开始。

## 本地运行

在仓库根目录执行以下命令，打开 **http://127.0.0.1:8080/**。静态服务只发布应用资源。首次在线打开并完成缓存后，两个模块都可以离线重新打开。设置中的「检查程序更新」会下载新版，点击「更新」后切换。修改离线资源时请同步提升 `sw.js` 中的版本号。

```sh
python3 serve.py
```

旧设备升级时继续使用原网站地址与浏览器配置文件。设备账本沿用 `airplane-pwa-v1`、`airplane-pwa-recovery-v1`、原草稿和恢复前快照。健康主账与健康备份在「健康 → 设置」中导入、导出。导入会先预览并要求确认。财务设置仍接受原始账本 JSON 和已有完整备份。

## 本地账本

- 健康页可导入本机主账。相同主账再次导入为无操作。历史更正保留原始数据，更新当日和周期结果。主账的库存快照由后续流水调整。
- 库存页可维护食品、录入采购、分装、盘点和查看批次与价格。健康采购可关联已有支出或打开财务表单确认新增支出。财务表单也可选择同步入库。饮食成本使用批次采购价分摊。
- 财务和健康的单独备份继续可用。健康设置可导出所选账本的统一备份，也可只恢复其中一个。确认前先预览，替换前在本机保存快照。
- 私人账本由本机账户码加密。普通设备账本可直接使用，数据存储随浏览器配置文件独立。

## AI 权限与服务端配置

1. 配置服务器的 `OPENAI_API_KEY` 和 `AI_USERS`。本地开发使用被 Git 忽略的 `worker/.dev.vars`，远程 Worker 使用 Secret。运行 `node worker/issue-account.mjs` 生成访问码和摘要，只将摘要放入 `AI_USERS` 的 JSON 数组。访问码私下发给受权使用者。
2. 分别运行 `npm run dev:api` 和 `python3 serve.py`。浏览器打开「AI 权限」，输入访问码后可查看当前月用量。访客可直接离线记账。升级自 0.8.1 的用户可以在此清理旧版浏览器密钥。
3. 在 `worker/wrangler.toml` 配置 `ALLOWED_ORIGINS`、`AI_MODEL`、`AI_MAX_OUTPUT_TOKENS`、`AI_REASONING`、`USER_RPM`、`USER_MONTHLY_CALLS`、`MONTHLY_BUDGET_CENTS`、`TOTAL_BUDGET_CENTS`。部署时，将本机以外的前端环境接到同源 `/api/assist` 和 `/api/usage`，并绑定 `QUOTA`。只支持有定价表的模型，服务端按标准价保守预留预算，有用量后按实际 token 结算，异常缺失用量时保留预留。每月额度按 UTC 月计算。
4. 文字录入、照片、运动、采购与晚餐规划提交前预览字段。食品库按文本相关度选择，规划包含近期三日的简要营养、周期、库存和用户填写的偏好。模型仅返回候选，当前账本由用户确认后写入。

接口与模型见 [Responses](https://developers.openai.com/api/reference/resources/responses/methods/create)、[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs) 和 [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)。

## 财务版本记录

- 首页账单与统计页支持左右滑动切换月份；向左进入下个月，向右回到上个月，同时保留顶部箭头和月份选择器。
- 查看历史月份时新增账单默认落在所查看月份的对应日期；若日期超过该月月底则取最后一天。保存后自动切到这笔记录所在月份，避免“保存后看不到”。
- 编辑已有账单后，如果内容发生变化但未保存，取消、点击背景或下拉退出都会先询问是否放弃修改；未改内容仍可直接退出。
- 设置新增“余额调整记录”，可查看每次余额修正的时间、增减额和调整后余额，也可删除错误调整并撤销。
- 统计页按月份状态显示：当前月显示预计支出，过去月显示最终结果，未来月显示“月份尚未开始”。
- 每日支出柱状图可点按查看具体日期和金额；分类过多时保留前 5 类并把其余合并为“其他”。
- 更新提示点 × 后，本次使用期间不再重复提醒；设置里的“程序更新”手动检查仍可重新显示。
- 月预算必须大于 0，避免“0 元预算”和“未设置预算”的语义冲突。
- 清空数据、导入备份、恢复前快照时同步清理未完成的记账草稿，避免旧草稿跨账本残留。
- 顶部余额统一改为“当前总余额”；旧版本遗留的未来日期账单在日期到来前不会提前影响当前总余额。

## 财务存储

- 数据主键：`airplane-pwa-v1`
- 恢复副本：`airplane-pwa-recovery-v1`
- 启动仍优先使用本地缓存；更新检查在后台进行，不阻塞打开。


## 0.7.15 启动优化
- 正常启动不再同步重写整份账本与恢复副本；只有真实迁移或保存数据时才写入。
- 当前月交易与当前总余额增加内存缓存，减少首屏重复扫描账本。
- 持久化存储检查和 Service Worker 注册维护移到首屏之后执行；更新检查仍保持后台自动发现。


## 0.7.16 收入同步预算

- 收入记账可选择“同步增加预算”，默认关闭。
- 开启后，收入金额加入该月总预算。
- 若收入发生在今天，该金额会完整增加今天的可支出额度，不会在当天平均摊到剩余日期。
- 编辑金额、日期、月份、关闭开关或删除收入时，预算会自动按账单状态回退/调整。


## 0.7.17 日常预算与预算外支出

- 支出记账可关闭“计入日常预算”。
- 预算外支出仍减少当前总余额，也仍计入总支出与支出分类统计。
- 预算外支出不会占用月预算，不参与“今日不宜超过”“今日还可支出”“较计划多支出/节省”等预算指标。
- 支出分类可设置“默认计入日常预算”；关闭后，新记该分类会默认标为预算外，单笔仍可修改。
- 旧支出默认继续计入日常预算，兼容现有账本。


## 0.7.18 月预算信息层级

- 月预算卡中的基础预算、收入增加、总支出、预算外改为独立分行显示。
- 仅调整信息层级与视觉，不改变任何预算计算规则。


## 0.7.19 首页信息密度微调

- 月预算卡恢复 0.7.17 的轻量文字样式，不再使用独立小面板。
- “基础 / 收入同步”保留在第一行；“总支出 / 预算外”移动到第二行。
- 当前总余额说明缩短为“按全部收入与支出计算”。
- 当天存在预算外支出时，提示缩短为“今日预算外 ¥X”。
- 仅调整首页信息层级，不改变预算、余额或统计计算规则。

## 0.7.20 收入默认同步预算

- 新建收入时，“同步增加预算”默认开启；只有不希望该笔收入进入预算时再手动关闭。
- 编辑已有收入仍保留该笔原有开关状态，不会把旧收入自动改成同步预算。
- 启动后台更新检查恢复为约 6 秒，保持既定更新策略。


## 0.7.21 收入预算开关重置

- 新建收入每次进入记账页时，“同步增加预算”都从开启状态开始，不继承上一次关闭状态。
- 新建收入切换分类或从支出切回收入时，该开关也恢复为开启。
- 编辑已有收入仍保留该笔账自己的开关状态。
