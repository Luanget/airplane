# Airplane PWA 0.9.24

Airplane 在设备上保存财务和健康账本。通过顶部设置旁的健康或财务图标切换模块。两页顶部共用 AI 图标，底部「＋」打开手动录入。健康首页底部按日期显示饮食、体重和运动记录，点击体重趋势可查看详情。

## 本地运行

在仓库根目录执行以下命令，打开 **http://127.0.0.1:8080/**。静态服务只发布应用资源。首次在线打开并完成缓存后，财务、健康和助手界面都可以离线打开。设置中的「检查程序更新」会下载新版，点击「更新」后切换。修改离线资源时请同步提升 `sw.js` 中的版本号。

```sh
python3 serve.py
```

旧设备升级时继续使用原网站地址与浏览器配置文件。设备账本沿用 `airplane-pwa-v1`、`airplane-pwa-recovery-v1`、原草稿和恢复前快照。在「健康 → 设置 → 数据与备份」勾选所需账本，再导出或选择文件。导入可先预览并确认。财务设置仍接受原始账本 JSON 和已有完整备份。

## 本地账本

- 健康首页的「健康档案」管理体检、指标趋势、症状和基础资料。附件可本机保存；同步包可勾选携带原件，命令行外部回写可用 `--include-medical-attachments`。
- 健康页可导入本机主账。相同主账再次导入为无操作。历史更正保留原始数据，更新当日和周期结果。主账的库存快照由后续流水调整。
- 库存页可维护食品、录入采购、分装、盘点和查看批次与价格。健康采购可关联已有支出或打开财务表单确认新增支出。财务表单也可选择同步入库。饮食成本使用批次采购价分摊。
- 在库存页的采购记录里编辑或撤销订单，关联支出与批次会一起处理。若批次已经消耗，先更正对应消耗记录再撤销。补货清单可从低库存加入食品，勾选后填入采购草稿。
- 财务和健康的单独备份继续可用。健康设置可导出所选账本的统一备份，也可只恢复其中一个。确认前先预览，替换前在本机保存快照。
- 账本按浏览器配置文件独立保存。有旧账户码的用户可以从应用原地址加 `?private=1` 打开旧账本导出，随后在健康设置中选择性恢复。

## AI 与 API Key

两页顶部的 AI 图标打开完整助手页面。对话、确认结果及个人 Skill 保存在当前浏览器。助手可提议修改 Skill，确认后保存。默认提示词由代码维护。收支、饮食、库存、分装和补货等候选经确认后写入本地账本。同一请求可核对并提交多项变更。保存后可使用更新后的数据继续本轮。

模型默认自动选择。明确的余额、晨重、部分饮食或称重和少量收支指令直接在本机处理。普通文本使用 Luna，截图使用 Terra，确实需要模型共同分析的跨领域任务使用 Sol。在助手设置里选定模型后，请求沿用该选择。在同页展开 API Key，或从财务、健康设置打开密钥配置。AI 新记录保存时会自动写入设备当前时间。请求包含本轮消息、当天日期、手选照片、已启用的 Skills 和近期聊天。近期历史默认最多 40 条和 16,000 字。「本轮上下文」可选「更多历史」（72 条、32,000 字）或「仅本轮」。超过档位时自动整理旧消息，每段滚动摘要最多 4,000 字，并保留本机原始对话。助手设置可切换、编辑 L 系列 Skill 或新建个人规则。账本查询默认开启，本轮需要的摘要会随请求发送，可在发送前关闭查询。回复正文实时显示，写入候选在完整校验后显示。可从对话列表删除本机聊天记录。

助手可按日期核对并删除饮食计划、实际饮食、体重、运动和未关联采购的收支。删除实际饮食会在同一次保存中撤销关联扣库并重算摄入。关联采购从库存页撤销。计划卡显示食材份量、五项营养、估算依据、已知成本、整餐和全天条件合计。计划与实际摄入分开。

聊天消息发送后立即保存在本机，回复逐步保存。重新打开后可查看收到的文字、重试中断的请求或继续核对待确认结果。多图识别结束后会有一条按照片归纳的总结。内置 Skill 收在 L 系列文件夹，个人规则可新建文件夹管理。个人修改遇到新版内置规则时，可以保留自己的版本或请 AI 融合，应用前先核对。

AI 可按数据集和原记录 ID 读取并建议修改健康、财务、库存、规则和助手设置。字段、关联和恢复流程见 [助手数据规范](docs/ASSISTANT_DATA.md)。

「任务用量与费率」显示按实际回执汇总的请求和缓存统计，并可导出本机任务日志。费率按模型修改，后续回执采用新价格。运行日志使用本机检查点和程序核对过的保存回执，账本事实在执行时查询。[OpenAI 缓存统计](https://developers.openai.com/api/docs/guides/prompt-caching)
近期执行回执会按当前会话或对象检索，发送前核对本机账本。采购截图可以缺少订单号，程序按凭据和商品明细检查重复。六天周期随实际摄入重算，缺报日的缺口显示未知。


打开 **http://127.0.0.1:8080/assistant/?demo=1** 可以点「更正饮食、记账并安排晚餐」体验批量确认和保存后续办，无需 Key。通过上方财务与健康图标看样例写入结果。已单独部署的 Worker 可继续使用原接口。

## 财务版本记录

- 首页账单与统计页支持左右滑动切换月份；向左进入下个月，向右回到上个月，同时保留顶部箭头和月份选择器。
- 查看历史月份时新增账单默认落在所查看月份的对应日期；若日期超过该月月底则取最后一天。保存后自动切到这笔记录所在月份，避免“保存后看不到”。
- 编辑已有账单后，如果内容发生变化但未保存，取消、点击背景或下拉退出都会先询问是否放弃修改；未改内容仍可直接退出。
- 设置新增“余额调整记录”，可查看每次余额修正的时间、增减额和调整后余额，也可删除错误调整并撤销。
- 统计页按月份状态显示：当前月显示预计支出，过去月显示最终结果，未来月显示“月份尚未开始”。
- 每日支出柱状图可点按查看具体日期和金额；分类过多时保留前 5 类并把其余合并为“其他”。
- 更新提示点 × 后，本次使用期间不再重复提醒；设置里的“程序更新”手动检查仍可重新显示。
- 月预算必须大于 0，避免“0 元预算”和“未设置预算”的语义冲突。
- 清空数据、导入备份、恢复前快照时同步清理未完成的记账草稿，避免旧草稿跨账本残留。
- 顶部余额统一改为“当前总余额”；旧版本遗留的未来日期账单在日期到来前不会提前影响当前总余额。

## 财务存储

- 数据主键：`airplane-pwa-v1`
- 恢复副本：`airplane-pwa-recovery-v1`
- 启动仍优先使用本地缓存；更新检查在后台进行，不阻塞打开。


## 0.7.15 启动优化
- 正常启动不再同步重写整份账本与恢复副本；只有真实迁移或保存数据时才写入。
- 当前月交易与当前总余额增加内存缓存，减少首屏重复扫描账本。
- 持久化存储检查和 Service Worker 注册维护移到首屏之后执行；更新检查仍保持后台自动发现。


## 0.7.16 收入同步预算

- 收入记账可选择“同步增加预算”，默认关闭。
- 开启后，收入金额加入该月总预算。
- 若收入发生在今天，该金额会完整增加今天的可支出额度，不会在当天平均摊到剩余日期。
- 编辑金额、日期、月份、关闭开关或删除收入时，预算会自动按账单状态回退/调整。


## 0.7.17 日常预算与预算外支出

- 支出记账可关闭“计入日常预算”。
- 预算外支出仍减少当前总余额，也仍计入总支出与支出分类统计。
- 预算外支出不会占用月预算，不参与“今日不宜超过”“今日还可支出”“较计划多支出/节省”等预算指标。
- 支出分类可设置“默认计入日常预算”；关闭后，新记该分类会默认标为预算外，单笔仍可修改。
- 旧支出默认继续计入日常预算，兼容现有账本。


## 0.7.18 月预算信息层级

- 月预算卡中的基础预算、收入增加、总支出、预算外改为独立分行显示。
- 仅调整信息层级与视觉，不改变任何预算计算规则。


## 0.7.19 首页信息密度微调

- 月预算卡恢复 0.7.17 的轻量文字样式，不再使用独立小面板。
- “基础 / 收入同步”保留在第一行；“总支出 / 预算外”移动到第二行。
- 当前总余额说明缩短为“按全部收入与支出计算”。
- 当天存在预算外支出时，提示缩短为“今日预算外 ¥X”。
- 仅调整首页信息层级，不改变预算、余额或统计计算规则。

## 0.7.20 收入默认同步预算

- 新建收入时，“同步增加预算”默认开启；只有不希望该笔收入进入预算时再手动关闭。
- 编辑已有收入仍保留该笔原有开关状态，不会把旧收入自动改成同步预算。
- 启动后台更新检查恢复为约 6 秒，保持既定更新策略。


## 0.7.21 收入预算开关重置

- 新建收入每次进入记账页时，“同步增加预算”都从开启状态开始，不继承上一次关闭状态。
- 新建收入切换分类或从支出切回收入时，该开关也恢复为开启。
- 编辑已有收入仍保留该笔账自己的开关状态。
